# Building Culture — Mobile Shell

Capacitor WebView wrapper for App Store and Google Play. Loads the live app at `https://app.buildingcultureid.space`.

## Quick start

```bash
npm install
npm run copy:icons
npm run assets
npx cap sync
npm run open:android   # or open:ios
```

Full docs: [docs/MOBILE_APP.md](../../docs/MOBILE_APP.md)

- **Bundle / package:** `space.buildingcultureid.app`
- **Deep link:** `buildingculture://auth/callback`
