## Getting Started

### Fork the Repository

```bash
git clone https://github.com/Laszlo23/xrpbaby.git
cd xrpbaby
```

### Install Dependencies

```bash
cd b3
npm install
```

### Run Development Environment

```bash
npm run db:start
npm run dev:platform
```

---

## Pull Request Process

1. Create a feature branch.

```bash
git checkout -b feature/amazing-feature
```

2. Make your changes.

3. Test your work.

4. Commit using clear commit messages.

```bash
git commit -m "Add amazing feature"
```

5. Push your branch.

```bash
git push origin feature/amazing-feature
```

6. Open a Pull Request.

## Code Standards

- Keep code clean and readable.
- Prefer reusable components.
- Write meaningful commit messages.
- Document important decisions.
- Add tests where appropriate.
- Respect existing architecture patterns.

---

## Reporting Issues

If you find a bug or have an improvement suggestion:

- Open a GitHub Issue
- Include steps to reproduce
- Include screenshots if applicable
- Explain expected behavior

---

## Community Guidelines

We welcome contributors from all backgrounds.

Please:

- Be respectful
- Be constructive
- Help others learn
- Assume good intentions
- Focus on collaboration

Harassment, discrimination, or toxic behavior will not be tolerated.
